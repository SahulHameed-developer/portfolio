# A Mohamed Sahul Hameed — Portfolio

Personal portfolio website for **A Mohamed Sahul Hameed**, Senior Full Stack Developer (Chennai).

Built with plain HTML, CSS and JavaScript — no build step. Features light/dark theme, responsive layout, animated stats, experience timeline, filterable projects and a downloadable resume.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Deployment

Hosted for free on **GitHub Pages** from the `main` branch (root folder).
