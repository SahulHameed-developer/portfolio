AI Portfolio Assistant

Node.js · Express · RAG · LLM

1 Problem

Recruiters want quick, specific answers (notice period, Node.js depth, AI experience) without reading a whole resume, and an LLM on its own can invent facts.

2 What I built

A Node.js + Express API that retrieves the relevant facts with a BM25 ranker, then asks Claude or OpenAI to answer only from them. It has input validation, rate limiting, a fallback when no LLM key is set, and automated tests.

3 Result

Answers grounded in real profile data, with sources returned for every answer. The same retriever runs in the browser, so you can try it on this page.
